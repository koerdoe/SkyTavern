# SkyTavern 使用文档

SkyTavern 是一个角色扮演聊天工具。它的核心想法是：**每一次回复是怎么产生的，你都能看清、能控制。**

发给模型的内容不是黑箱。你在左栏看到的“请求结构”，从上往下就是实际发出去的顺序；点任何一条，都能看到它最终变成了什么。

## 名词速查

- **词条**：一段会被放进请求的文字。预设、角色卡、用户自机、世界书都由词条组成。
- **分区**：词条放在请求里的哪一段：系统提示、正文前、正文、正文后。
- **层**：聊天记录里的一条消息。重新生成会在同一层产生多个**候选**，可以左右切换。
- **变量**：挂在某一层上的操作（如 `hp -= 5`），从初始值开始逐层重放得到当前值。
- **正则脚本**：作者写的查找替换规则，可以改正文、产生变量操作、改显示效果，也可以在消息开头或末尾固定插入一段内容（例如 HTML 组件）。
- **附加消息**：挂在某条消息末尾的非正文内容（例如组件写下的商店记录），下一轮作为一条 user 消息紧跟在那条消息之后发送。
- **召回**：从已经裁出正文窗口的旧记录里，找出和当前话题相关的片段放进请求。
- **附件**：随消息按原文件发送的图片、PDF 等。
- **开场白**：角色卡里写好的第一条 AI 消息，新对话以它开始。

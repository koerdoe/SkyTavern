# 上手

## 启动

需要 [Node.js](https://nodejs.org/) 22.18 或更新的版本。

- Windows：双击 `start.bat`。
- macOS / Linux：运行 `./start.sh`。

第一次启动会自动安装依赖、构建界面，然后打开浏览器（默认 http://127.0.0.1:7860）。之后再启动就很快了。

可选参数：`--no-open` 不自动打开浏览器，`--rebuild` 强制重新构建界面。

## 账号与访问

没有 `config.json` 时，不需要登录，直接以 root 身份使用。

要设账号密码，或者让局域网里的其他设备访问，把 `config.example.json` 复制成 `config.json` 再修改：

```json
{
  "host": "0.0.0.0",
  "port": 7860,
  "auth": {
    "enabled": true,
    "users": [{ "name": "alice", "password": "change-me" }]
  }
}
```

- `host` 设为 `0.0.0.0` 才能被其他设备访问。
- 开启认证后，浏览器会弹出原生的登录框。每个账号的数据互不相干。
- 改完配置要重启才生效。

## 配置模型

点顶栏的模型按钮（没选模型时显示为红色的“选择模型”）：

1. 新建一个配置，选择协议：OpenAI Chat Completions、OpenAI Responses、Claude Messages 或 Gemini。
2. 填 Base URL 和 API 密钥。OpenAI 的地址写到 `/v1` 为止；Claude 和 Gemini 只写域名即可。
3. 点“拉取列表”选模型（改了地址不用先保存），保存后点“使用这个”。

API 密钥只保存在服务端，界面和请求预览里都看不到它。

## 开始对话

右栏选一个角色，点“开始对话”。角色卡写了开场白的话，新对话以它作为第一条消息；有多个开场白时，可以在第一条消息上左右切换。输入框按 Enter 发送，Shift+Enter 换行。

从酒馆搬卡：右栏列表上方的导入按钮，见[导入](import.md)。角色详情里点头像可以换图。

新账号自带一张示例角色卡「万界商铺」：你是顾客，AI 是老板，回复下面有一个可以买卖的货架。它演示了变量、正则和组件怎么配合，见[变量与正则](variables.md#示例万界商铺)。

- **停止**：生成中可以随时停，已经收到的部分会保存为“未完成”，并参与后面的对话。
- **续写**：不发新消息，让角色接着说。
- **重新生成**：在 AI 回复上点刷新图标。新的回复成为这一层的另一个候选，用左右箭头切换。
- **编辑 / 删除**：消息上的工具按钮。删除有多个候选的层时，只删当前这个候选。

关掉页面不会中断生成，回来时会接着显示。

## 附件

输入框旁的回形针可以给这条消息加文件（可以多个，单个不超过 30 MB）。附件**按原文件发送**，不做转换：

| 协议 | 图片 | PDF | 文本文件 | 其他 |
|---|---|---|---|---|
| Claude | png、jpeg、gif、webp | 支持 | 作为文本文档 | 报错 |
| OpenAI Chat / Responses | 支持 | 作为文件 | 作为文件 | 交给接口判断 |
| Gemini | 支持 | 支持 | 支持 | 交给接口判断 |

模型或渠道不支持时，那次生成会报错并显示接口给的原因，换个模型或去掉附件即可。

- 附件跟着消息走：重新生成、分支、续写时照常发送；预览和请求体里显示为 `sky-attachment:…` 占位，真正发送时才换成文件内容。
- 相同内容的文件只存一份。消息删掉后附件不会立刻消失，没被任何会话引用满 7 天才自动清理（config.json 的 `attachmentRetentionDays`）。在 /admin 可以看到全部附件和引用情况。

## 会话与分支

中间栏左下角的按钮显示当前会话，点开是这个角色的全部会话，按**分支关系排成树**：

- 点任意一个就切过去。右上角可以新建会话、全部展开，或者放大成整棵树。
- 每一行显示名字（没起名时按创建时间）、条数、最后活跃时间和最后一句话的开头；分支会标出“从第几条分支”。
- 悬停一行可以改名、删除。删除一个会话时，它的分支改挂到上一级，树不会断。

**分支**：消息的工具按钮里点分支图标，会把到这条消息为止的内容（包括每层的全部候选、变量操作、附加消息）复制成一个新会话，挂在当前会话下面，然后切过去。原会话不受影响，想试另一种走向时很方便。

## 界面导览

| 位置 | 内容 |
|---|---|
| 左栏“请求结构” | 当前预设、角色卡、自机、世界书的全部词条，按实际发送顺序排列。见[请求结构](request-structure.md) |
| 中间 | 对话；点“预览”切换为实际发送的请求 |
| 右栏 | 角色、用户自机、世界书的列表和详情 |
| 顶栏 | 预览、正则、模型、白天/夜晚、系统设置、文档、管理与调试（/admin） |
| 中间栏左下角 | 当前会话；点开切换会话、查看会话树 |

手机上左右两栏收在顶栏两侧的按钮里，点开后全屏显示。

**系统设置**（顶栏齿轮）跟着账号走，换设备也一样：

- **外观**：主题、阅读模式（短对话：气泡、字大；长对话：紧凑、适合长文）、每次加载的消息条数。
- **风格**：自己写 CSS 改界面，可以存多套，一键切换。编辑时实时预览，保存后生效；选“默认”就是不用自定义风格。
- **token 预估**：自动选分词器时模型名优先还是接口类型优先，见[请求参数与缓存](request-params.md#按模型名选分词器)。
- **召回**：默认关闭。打开后用嵌入模型从较早的聊天记录里找出和当前话题相关的片段，见[请求结构](request-structure.md#召回)。

## 管理与调试（/admin）

- **Debug 请求**：截取当前请求，直接改请求体 JSON 再发送，回复照常写进聊天。截取之后改预设、改会话都不会影响这份快照。
- **最近一次发送的请求**：只读，便于核对。
- **局部变量**：逐层查看变量操作和数值。见[变量与正则](variables.md)。
- **召回索引**：向量召回时，当前会话建好了多少索引、后台出错的原因，可以手动补齐。
- **附件**：全部附件的大小、引用情况，没被引用的可以删除。
